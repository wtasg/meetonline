3. Working with branches

```bash

# STEP 1
## Update main
git checkout main # git switch main
git fetch --all
## make sure you are on main branch
git branch
# * main
git pull --rebase origin main 


## STEP 2
## Create a branch where you will work:
git switch --create branch_name
## verify:
git branch
# * branch_name


## STEP 3
## Work here on branch_name
git add .
git commit --message=""
## pull latest from main and merge to current branch
git pull --rebase origin main
git push origin branch_name
## PR...
```
